# Minimal Widgets

Personal Android 10+ widgets using Kotlin, Compose, Material 3 and Glance.

Includes the gallery-first launcher, equal-sized cards, seven accent swatches and hue picker, DataStore persistence, and refresh of placed widgets. Default accent: #FFC000.

Widgets: clock/date, photo, app folder, media volume, Wi-Fi settings, mobile data settings and personal note. Connectivity widgets open Android panels. Tap a placed photo/folder/note widget to configure it. Each instance has separate settings. Photo pixels keep their original colors.

Package: com.aarish.minimalwidgets. Source was reconstructed from the brief; original files were not supplied.

See [BUILDING.md](BUILDING.md) for build commands and verification limits. The app and test APKs compile. Device acceptance checks remain pending; do not close those issue checklist items until tested.
